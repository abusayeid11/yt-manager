## API Endpoints

| Endpoint | Description |
|----------|-------------|
| POST /api/v1/transcript | Get timestamp-based transcript segments |
| POST /api/v1/transcript/semantic | Get AI-generated semantic chapters |

## Request Format

Regular Transcript:
{
  "url": "https://youtube.com/watch?v=VIDEO_ID",
  "segmentationType": "TIMESTAMP",
  "segmentDuration": 60
}

Semantic (AI):
{
  "url": "https://youtube.com/watch?v=VIDEO_ID"
}

## Response Structure

Snippets (both endpoints):
{
  "snippets": [
    {"startTime": "0:00", "start": 0.0, "duration": 5.0, "text": "..."}
  ]
}

Segments (timestamp-based):
{
  "segments": [
    {"startTime": "0:00", "start": 0.0, "end": 60.0, "text": "..."}
  ]
}

Segments (semantic):
{
  "segments": [
    {"startTime": "0:00", "start": 0.0, "end": 120.0, "text": "...", "title": "Introduction"}
  ]
}

## Python Script Usage

Regular transcript
python scraper.py https://youtube.com/watch?v=VIDEO_ID

With semantic segmentation
python scraper.py https://youtube.com/watch?v=VIDEO_ID --semantic

## Key Features Implemented

1. Transcript Extraction
   - Fetches YouTube video transcripts using youtube-transcript-api
   - Supports various YouTube URL formats

2. Timestamp-Based Segmentation
   - Client-side re-segmentation with configurable duration (30s/60s/90s)
   - Sentence-aware extension logic
   - Accurate end timestamps using snippet duration

3. Semantic Segmentation (AI-Powered)
   - Uses Gemini 1.5 Flash for topic-based chapter detection
   - Separate endpoint for on-demand AI processing
   - Graceful degradation when API key not set

4. Frontend UI
   - Basic/Semantic toggle buttons
   - Copy to clipboard functionality
   - Visual chapter titles for semantic segments

## Architecture

Frontend (Next.js)
  └── POST /api/v1/transcript or /transcript/semantic
       ↓
Backend Controller (Spring Boot)
  ├── TranscriptController → PythonExecutionService → TranscriptProcessor
  └── SemanticController → SemanticService → PythonExecutionService
       ↓
Python Scraper (scraper.py)
  ├── youtube-transcript-api for transcripts
  └── google-generativeai for semantic boundaries
